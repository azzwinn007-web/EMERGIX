# 🚨 EMERGIX — Emergency Intelligence & Response Network

EMERGIX is a hackathon prototype designed to improve emergency medical response by connecting patients with hospitals and providing real-time hospital resource information.

## ✨ Features

- Patient and Hospital portals
- Patient emergency assessment
- AI-assisted emergency recommendations
- Medical profile for emergency responders
- Hospital network and availability
- Hospital Command Center
- Live ICU and emergency bed availability
- Ventilator and ambulance availability
- ER waiting time
- Oxygen and blood supply status
- CT scanner availability
- SQLite database for hospital telemetry
- FastAPI backend
- React + Vite frontend

## 🏗️ Tech Stack

- React
- Vite
- JavaScript / JSX
- CSS
- Python
- FastAPI
- SQLite
- Uvicorn
